# Переводы Орбиты

Орбита выпускается на **английском** и **русском** целиком: интерфейс, встроенный правиловый движок (работает без ключа ИИ), промпты для ИИ и
демо-данные. Язык интерфейса по умолчанию следует за браузером (Настройки → «Язык»: «Авто», English или Русский; выбор есть и в онбординге).
Добавить ещё один язык — в основном работа переводчика: один JSON-файл и несколько строк кода.

## Как это устроено

Слой переводов маленький и без зависимостей (`src/i18n/`).

- **Ключ — английский текст.** В коде `t('Sign in')`. Непереведённый текст откатывается на английский, а не показывает технический ключ.
- Остальные языки — JSON-словари в `src/i18n/locales/<id>.json`: английский текст → перевод. Они подгружаются лениво, англоязычные пользователи их не скачивают.
- **Подстановки** в фигурных скобках: `t('Hello, {name}', { name })`. Перевод обязан сохранить те же подстановки.
- **Множественное число:** `tn(count, '{n} day', '{n} days')`. В словаре такое сообщение — **массив форм** в порядке, заданном списком `plural` языка в
  `LOCALES` (английский: `one, other`; русский: `one, few, many, other`). `{n}` подставляется автоматически.
- **Контекст** разводит одинаковые английские слова с разным переводом: `t('Call', undefined, 'verb')` хранится под ключом `verb\u0004Call` (контекст,
  управляющий символ U+0004, текст).
- **Константы уровня модуля** не могут вызывать `t()` при загрузке. Пометьте текст через `msg('...')` и переведите там, где показываете, `t(value)`,
  либо используйте геттер (`get label() { return t('Work') }`).
- **JSX с разметкой внутри фразы:** `tx('Connected · {model}', { model: <b>Claude</b> })` из `src/i18n/react`.
- **Пары «рядом»** для текста, который не часть интерфейса (промпты ИИ, демо-контент, словарь правилового движка): `pick(en, ru)`.
- Ключи должны быть **строковыми литералами** (без шаблонных строк с `${...}`): именно так проверка находит их все.

## Добавить язык

Допустим, добавляем немецкий (`de`).

1. Зарегистрируйте его в `src/i18n/index.ts`:
   - добавьте `'de'` в тип `Locale`,
   - добавьте строку в `LOCALES`: `{ id: 'de', name: 'German', native: 'Deutsch', tag: 'de-DE', plural: ['one', 'other'] }`
     (`plural` — категории множественного числа CLDR вашего языка в порядке массивов словаря),
   - добавьте загрузчик в `loaders`: `de: () => import('./locales/de.json').then(m => m.default as Dictionary)`.
2. Создайте `src/i18n/locales/de.json`. Проще всего скопировать `ru.json` и заменить значения (ключи оставить). `npm run i18n:check` покажет все
   отсутствующие сообщения и несовпадающие подстановки:
   ```bash
   npm run i18n:check             # падает на отсутствующих и повреждённых переводах
   npm run i18n:check -- --strict # падает ещё и на неиспользуемых
   ```
3. Запустите приложение (`npm run dev`), переключите язык в Настройки → «Язык» и пройдите по экранам. Длинные слова стоит проверить на телефоне.

Этого хватает для всего интерфейса. Дальше — про части, которые «думают».

## Движок, промпты и демо-данные

- **Правиловый движок** (`src/ai/providers/mock-extract.ts`, `src/search/`, `src/ai/ask.ts`) понимает ввод на английском и русском одновременно, какой
  бы ни был язык интерфейса; то, что он *пишет*, следует языку интерфейса. Чтобы научить его новому языку ввода, дополните списки слов и шаблоны и
  добавьте тесты по образцу существующих.
- **Промпты ИИ** (`src/ai/prompts/`) есть на английском и русском через `pick`. Для другого языка расширьте вызовы `pick` или добавьте строку с
  просьбой отвечать на этом языке; ключи структурного JSON остаются английскими.
- **Демо-данные** (`src/db/seed/content/`) написаны на обоих языках: записи, цитаты (цитата обязана быть дословной частью записи, это проверяет
  валидатор), люди, паттерны и обзоры. Без пакета для вашего языка используется английское демо.
- **Распознавание речи** использует `tag` локали (`de-DE`) для браузерной диктовки и код языка для серверной транскрипции.
- **Русские имена** склоняются там, где это нужно фразе (`src/i18n/ru-names.ts`); в других языках имена показываются как написаны.

## Тесты

Набор тестов идёт в **русской** локали (исходный язык приложения) с фиксированным часовым поясом. Тест английского поведения вызывает
`setLocale('en')` и затем возвращает `'ru'` (см. `src/__tests__/english-ui.test.tsx`: он обходит основные экраны и проверяет, что кириллица не
просачивается в английский интерфейс). Для нового языка стоит добавить похожий дымовой тест.

## Памятка переводчику

- Сохраняйте тон оригинала: спокойный, короткий, дружелюбный, без жаргона и восклицательных знаков, если их нет в английском.
- Не переводите названия продуктов (Orbita, Aster, Anthropic, OpenAI, Claude, Supabase).
- Приложение говорит с одним человеком о его мыслях: выберите одну форму обращения и держитесь её везде, предпочитайте формулировки, не зависящие от пола.
- Держите словарь единым: *запись*, *решение*, *обязательство*, *прогноз*, *чек-ин*, *паттерн*, *обзор*, *орбита*.
