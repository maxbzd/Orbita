# Своя копия на хостинге

Орбита — статический сайт: `npm run build` создаёт `dist/`, который отдаст любой статический хостинг. Серверной части нет. Пути
относительные (`base: './'`), поэтому приложение работает и из корня домена, и из подкаталога.

```bash
git clone https://github.com/maxbzd/Orbita.git && cd Orbita
npm ci
cp .env.example .env     # по желанию: значения для облачной синхронизации, см. CLOUD.md
npm run build            # проверка типов и сборка в dist/
```

Отдавайте по **HTTPS**: микрофону, service worker и «Добавить на экран „Домой“» нужен безопасный контекст (`localhost` для локальных
проверок считается безопасным).

## GitHub Pages (автоматически)

1. Сделайте форк репозитория.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Каждый пуш в `main` запускает `.github/workflows/deploy.yml`: установка, проверка переводов, тесты, сборка, публикация.

Если используете облачную синхронизацию, добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_KEY` как **переменные** репозитория (Settings →
Secrets and variables → Actions → Variables) и передайте их в `env` шага сборки. Это публичные значения; ключ `service_role` не добавляйте никогда.

## Netlify, Cloudflare Pages, Vercel, любая статика

Команда сборки `npm run build`, каталог публикации `dist`, Node 22.23.4 или новее (задайте `NODE_VERSION` у хостинга). Редиректы не нужны: используется hash-роутер (`#/...`).

## На своей машине или в своей сети

`npm run preview` отдаёт собранную версию (с `-- --host` она доступна с телефона в той же сети; микрофону нужен HTTPS, поэтому для проверок на
телефоне используйте туннель или настоящий хостинг).

## Свой сервер ИИ

Политика безопасности контента в `index.html` разрешает запросы только к перечисленным хостам (`api.anthropic.com`, `api.openai.com`,
`api.groq.com`, `openrouter.ai`, Supabase). Чтобы использовать другой OpenAI-совместимый сервер (локальный Ollama, прокси), добавьте его адрес в
`connect-src` в `index.html` **до сборки**. CSP в `<meta>` нельзя ослабить в рантайме, и это сделано намеренно.

## Обновления

Service worker регистрируется с `registerType: 'prompt'`: новая версия ждёт следующего запуска и не перезагружает страницу посреди записи.
Ваши данные лежат в браузере, обновления их не трогают.

## Установка на телефон

Откройте сайт в Chrome (Android) или Safari (iPhone) → **«Добавить на экран „Домой“»**. На Android появятся ярлыки «Новая запись» и «Чек-ин», а
Орбита станет доступна в системном меню **«Поделиться»** (отправленный в неё текст превращается в запись).
